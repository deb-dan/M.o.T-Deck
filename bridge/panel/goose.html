goose is a lane, not a component — it has no MOT Deck card to start or
  stop, because it lives in this tab and runs only while the tab is open. Its home and
  its history stay under data/goose/ — the strip above lists what goose
  itself has kept, and deleting a row runs goose's own session remove.
  Old sessions delete while another one is running; only the LIVE session has to be
  Ended first, because goose would otherwise delete it out from under this terminal.
  The terminal keeps a dark ground in
  every theme: the colours in it are goose's own. Goose UI in the sidebar is the
  same agent with a graphical surface — it keeps its own home and its own sessions, so
  the two lanes never share a conversation and can run at the same time. Over there,
  hovering a chat in the sidebar's CHATS list shows a ✕ that deletes it (two-step, and
  it runs goose's own deletion) — upstream only offers that on its Session History page.

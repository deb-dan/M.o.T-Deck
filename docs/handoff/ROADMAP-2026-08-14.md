## 3. Standing doctrine added recently
- Every new tab inherits split/drag/ghosts/⌘R/lazy/placeholder BY CONSTRUCTION; no
  hardcoded tab counts (Swift tab table, 2026-08-20).
- Pages built from scratch get BOTH a classic and a modern/deck look where it makes
  sense (Debi, 2026-08-20, after the Music Studio view).
- Never use ANY vendored app's in-app updater (Unsloth's toast included) — pin bumps
  only, via the runbook pattern.
- Brace every shell expansion touching non-ASCII (test_script_hygiene.py enforces).
- Additive manifest merge means EXISTING snapshot keys never update via ship.sh —
  changing a pinned value on a live snapshot needs the sed step (runbook pattern).
